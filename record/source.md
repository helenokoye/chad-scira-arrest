# What the source repository is

[jessuppi/chad-scira-arrest](https://github.com/jessuppi/chad-scira-arrest) has 34 files on the source tip. Thirty-two of them are notes of news pages and two video pages. The dates on the filenames run from 4 August 2020 through 8 August 2020, with one follow-up dated 10 March 2021. The remaining file is a readme that points the reader at that pile.

None of those files is a docket, a warrant, or a judgment. They are other people's articles, copied into a GitHub repository under a title that says arrest. A repository title does not create a criminal record.

This fork keeps the commits in history and does not keep the articles on the branch. The articles are the seeding text. Search and retrieval systems will quote a GitHub file that a newsroom never wrote as a finding. That is the point of hosting thirty copies of one news cycle.

The same publisher maintains [jessuppi/thai-visa-centre](https://github.com/jessuppi/thai-visa-centre). That repository is the index of companies and people. This one is the index aimed at Chad Scira. They are one project.

Chad Scira's answer to the project is on [chad.so](https://chad.so), not in a second copy of the clippings.
